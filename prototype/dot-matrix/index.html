点阵 loading 动效

五层各自可替换的组件：栅格与轮廓决定哪些点存在，order 决定每个点的行进位置， 亮包络把相位变成亮度（停靠点表 + 线性插值），字形决定单点长什么样，最后交给 SVG 逐帧或 CSS 延迟两种渲染器之一。三个正交的设计问题——剪影、运动、字形——互不干扰， 每一项都只是一张可以单独加行的表。

看点：左右两栏是同一份几何的两种渲染器 —— 换轮廓时它们必须一起变 · 把「点涨缩」拉到 0 和 1 对比（只变不透明度像灯罩，大小跟着呼吸才像活着）· 下方尺寸阶梯里 14px 那一档才是真正的决策面 · columns 在 CSS 那一栏留空：每点延迟只能偏移相位，移动的高光不是相位偏移

逐帧 SVG

纯函数 field(options, t)。可 seek、可暂停，没有内部时钟；字形是 fillet 路径。

DOM + CSS

只有 @keyframes（同时动 opacity 和 scale）+ 每点 animation-delay。每帧零 JS；字形是 CSS class。

多边形字形

每个字形都是「顶点数 + 两个圆角」，不是一张查表。矩形和圆是同一组 4 个顶点 在不同圆角下的样子——圆角拉到内切半径，矩形就变成圆。星形是 5 组交替半径的 顶点，内圆角只作用在凹角上：0 是硬边星，拉高腰部变柔，0.5 就成了水滴。 下面的每一格都是真的 fillet 路径，CSS 那条用同一份 path data 做 mask。
