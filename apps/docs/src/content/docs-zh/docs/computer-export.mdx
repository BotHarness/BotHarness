Computer 的整套桌面——登录态、书签、下载与文件——都保存在一个 Docker 具名卷上。**导出**把整个卷打包成单个归档；**导入**在本机或另一台机器上还原。一个文件出去，一个文件进来。

## 文件都放在哪里

- 所有持久内容都在挂载于 `/config` 的具名卷上（即桌面用户的家目录）。删掉容器是安全的；卷本身就是这台 Computer。
- **工作区约定**：人类与 Bot 产出的文件放在 `~/workspace`（即 `/config/workspace`）。每次启动都会在缺失时创建该目录；它在卷上，会随导出 → 导入一起迁移。浏览器状态则单独存放在 `~/.config/chromium` 下。
- **导出目录**是*宿主机*上的路径：未配置时默认为 `~/Desktop/BotHarness Exports`（家目录没有 Desktop 时为 `~/BotHarness Exports`），在 **Settings → BotHarness → Computer** 中有目录选择器时可以更改。归档文件出现在该目录；导入也只列出并接受该目录内的文件。

## 导出

1. 打开 **Settings → BotHarness → Computer**。无需任何配置——导出目录已显示当前（默认）路径；有目录选择器时可以用**选择…**换一个目的地。
2. 点击**导出到…**（或**导出**），选择目标目录并确认。Computer 会先优雅关闭浏览器、停止、打包卷，并在原本运行时重新启动；设置行会实时显示阶段与已用时。
3. 完成后，提示会显示归档路径——一个带时间戳的 `.tar` 文件。在没有可用选择器（目录固定）的部署上，文件夹还会自动在宿主机文件管理器中打开。

## 在另一台机器上导入

1. 在目标机器上安装容器运行时（Docker 或 Colima）以及带 BotHarness 的 DeepSeek Harness；先把 profile 启动一次让 Computer 插件加载。
2. 把 `.tar` 归档拷过去（U 盘、`scp`、网络共享均可）。
3. 在 **Settings → BotHarness → Computer** 里查看目标机器的导出目录（默认路径无需配置即可使用），并把归档放进该目录。
4. 点击**导入…**，选中归档并确认。Computer 会重建卷、解包并启动——登录态、书签和 `~/workspace` 里的文件都会回来。

## 体积与耗时预期

- 归档是卷内容的未压缩 tar。正常使用后卷通常在 **1 GB 左右**（浏览器配置、缓存与工作区文件）；可查看生成的文件大小，或用 `docker system df -v` 查看在线卷。
- 在开发机上，约 1 GB 的本地导出与导入通常各需**不到一分钟**（受磁盘限制；导入还会校验固定镜像已存在）。

## 把归档当作机密对待

归档里含 Computer 的 Cookie 与已保存的登录态——敏感度等同浏览器配置备份，请相应地存放与传输。它是 profile 级的导出面，永远不并入 PersonaBot 导出。
