# 模型

打开 **Bot 私聊 → Channel sidebar → 模型**。这里用两张卡片显示这个 Bot 正在用的模型；收起时，标题右侧也会显示主模型的「模型 · 思考强度」，不用展开就能核对。

![Bot 私聊侧栏中的模型分区，显示主模型与执行模型](/guides/channel-sidebar/14-model-zh.webp)

## 读懂两张卡片

| 卡片     | 显示内容                                                                        |
| -------- | ------------------------------------------------------------------------------- |
| 主模型   | 和你对话、分派任务时使用的「模型 · 思考强度」。来自预设时，多一个预设名称标签。 |
| 执行模型 | 分派出去的任务默认使用的模型。允许任务另选其他模型时，显示「另 N 个可选」。     |

## 修改模型

点击任一张卡片，打开 **模型** 弹窗：

![从侧栏打开的模型弹窗](/guides/channel-sidebar/15-model-dialog-zh.webp)

1. 在 **主模型** 和 **执行模型** 里输入关键词过滤模型列表，再点选；模型支持思考强度时，在下方选择 **默认** 或具体档位。
2. 需要让任务另选模型时，在 **可选的执行模型** 里添加，并勾选允许的思考强度。
3. 点 **保存**。改动从之后的回合生效；已创建的任务继续使用创建时的模型。

预设是可选的。有已保存的预设时，弹窗顶部可以 **从预设填入**；之后改动任何一项，就不再关联这个预设。想把当前设置留着以后复用，点 **另存为预设**，输入名称后保存，这个 Bot 会直接使用新预设。

各字段的含义和 provider 配置见 [模型教程](/zh/docs/model-setup)。

## 隐藏或移动

和其他分区一样，可以在 **编辑侧栏** 中移动或隐藏 **模型**，见 [显示与布局](/zh/docs/channel-sidebar/display)。
