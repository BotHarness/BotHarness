# 外部连接器

打开 **Bot 私聊 → Channel sidebar → 外部连接器**。外部连接器决定已授权外部会话中的哪些消息进入这个 Bot：进入本私聊的消息历史，或 **仅 Bot Inbox**。它与 Bot 的发言身份分开管理；请先在[外部身份](/zh/docs/channel-sidebar/external-identities)中绑定身份。

![外部连接器分区，包含连接器行与授权行](/guides/channel-sidebar/20-external-connectors-zh.webp)

## 读懂每一行

| 行                   | 显示与作用                                                                                                                                                                              |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 每个连接器一行       | 连接器名称、状态标签（**正在收件**、**正在连接**、**已暂停** 或 **暂不可用**；不添加私聊历史时另有 **仅 Bot Inbox**），以及「平台 · 外部会话 · 接收条件」。右侧 Switch 暂停或恢复收件。 |
| **+ 添加外部连接器** | 把已授权的会话接入本私聊或仅 Bot Inbox。                                                                                                                                                |
| **授权外部会话**     | 打开 **外部会话授权**。已授权目标后，这一行显示目标名称、状态标签和「平台 · 账号」。                                                                                                    |

**连接器决定收什么，Bot 的[唤醒策略](/zh/docs/channel-sidebar/wake-policy)决定何时处理。**

## 授权外部会话

三步的关系：先在[外部身份](/zh/docs/channel-sidebar/external-identities)绑定身份（Bot 以谁发言），再授权具体外部会话（可以收发哪个群或私聊），最后可选添加外部连接器（消息进入哪里）。

可选的会话来自平台侧：在平台后台给应用开好权限、把机器人拉进群，再在 **设置 → IM机器人** 的账号投递设置中保存 **发送目标**。收到某个会话的消息**不会**自动生成授权；未授权的会话即使 @ 机器人，消息也不会进入 Bot Inbox。授权只能在这里手动完成，之后可以修改或撤销。

1. 点击 **授权外部会话**。
2. 选择已绑定的 **IM账号** 和保存的 **发送目标**，点击 **绑定并授权此目标**。核对群名称、账号和本地收件位置。
3. 在同一弹窗中，还可以设置 **本地收件位置**、此群的收件与唤醒、话题跟进，向目标发送消息，并查看 **最近发送**。
4. **刷新** 重新读取当前状态；**撤销此目标授权** 移除授权。

![外部会话授权弹窗](/guides/channel-sidebar/22-conversation-authorization-zh.webp)

## 添加外部连接器

1. 点击 **+ 添加外部连接器**。
2. 选择 **已授权来源**。列表为空时，先授权外部会话。
3. 选择投递目标：本私聊的消息历史，或 **仅 Bot Inbox**。
4. 填写易识别的 **连接器名称**，选择接收条件后保存。

添加连接器不会创建外部账号或新增授权。这些弹窗中的下拉框都支持搜索，输入文字即可筛选。

## 编辑、暂停或删除

点击连接器行，打开 **编辑外部连接器**。修改 **连接器名称**、**接收条件**（继承、仅收 @ 接收身份、所有普通文字消息）或启用开关，然后点击 **保存外部连接器**。**删除** 需要确认（**删除此连接器**）。暂停会保留配置与历史；删除不会删除已收到的消息。

![编辑外部连接器弹窗](/guides/channel-sidebar/21-external-connector-dialog-zh.webp)

本地群聊仍在群的详细 Profile 中管理外部连接器。平台配置：[Lark / 飞书](/zh/docs/lark-connection)、[Slack](/zh/docs/slack-connection)、[个人微信](/zh/docs/wechat-connection)。返回[侧栏总览](/zh/docs/channel-sidebar)。
