# 外部连接器

打开 **Bot 私聊 → Channel sidebar → 外部连接器**。这里列出同步到这个 Bot 的 Channel 的外部会话，并保留一个高级操作。收消息和回复都不需要它：[绑定应用](/zh/docs/channel-sidebar/external-identities)即可，会话也在那里管理。以后，Webhook 等单向输入流也会放在这里。

![外部连接器分区：一个已同步的会话和高级发送目标行](/guides/channel-sidebar/20b-external-connectors-zh.webp)

## 读懂每一行

| 行                       | 显示与作用                                                                                                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 每个同步一行             | 同步名称、状态标签（**正在收件**、**正在连接**、**已暂停** 或 **暂不可用**；不添加私聊历史时另有 **仅 Bot Inbox**），以及「平台 · 外部会话 · 接收条件」。右侧 Switch 暂停或恢复收件。 |
| **保存发送目标（高级）** | 仅用于不能列出或直接发往会话的应用：保存一个目标，让 Bot 主动发消息。收消息和回复不需要它。                                                                                           |

还没有同步时，这里会提示从哪里开始：在「外部身份」打开应用，在会话行点击 **同步**。

**同步决定收什么，Bot 的[唤醒策略](/zh/docs/channel-sidebar/wake-policy)决定何时处理。**

## 编辑、暂停或移除同步

点击一行，打开 **编辑外部连接器**。修改名称、**接收条件**（继承、仅收 @ 接收身份、所有普通文字消息）或启用开关，然后点击 **保存外部连接器**。**删除** 需要确认。暂停会保留配置与历史；删除不会删除已收到的消息。

![编辑外部连接器弹窗](/guides/channel-sidebar/21-external-connector-dialog-zh.webp)

## 高级：保存发送目标

Lark、Slack 和 Discord 应用可以直接发往会话，永远不需要这一步。对于 Provider 不能列出或直接发往会话的应用：

1. 在 **设置 → IM机器人** 的账号投递设置中保存 **发送目标**。
2. 点击 **保存发送目标（高级）**，选择已绑定的 **IM账号** 和保存的 **发送目标** 并确认。
3. 在同一弹窗中，还可以向目标发送消息并查看 **最近发送**；**撤销此目标授权** 会移除它。

![发送目标弹窗](/guides/channel-sidebar/22-conversation-authorization-zh.webp)

本地群聊仍在群的详细 Profile 中管理外部连接器。平台配置：[Lark / 飞书](/zh/docs/lark-connection)、[Slack](/zh/docs/slack-connection)、[个人微信](/zh/docs/wechat-connection)。返回[侧栏总览](/zh/docs/channel-sidebar)。
