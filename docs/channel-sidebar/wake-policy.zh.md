# 唤醒策略

打开 **Bot 私聊 → Channel sidebar → 唤醒策略**。唤醒策略按消息来源决定这个 Bot 是立即被唤醒、攒够一批再处理，还是只记录不唤醒。收起时，标题右侧显示普通群消息的处理方式，例如 **群聊 · 汇总 · 5 条 / 30 秒**。

![唤醒策略分区，每个来源一行](/guides/channel-sidebar/16-wake-policy-zh.webp)

## 读懂每一行

每行是一种来源，第二行是当前规则；**已修改** 表示你或 Bot 改过这条规则，不再是内建默认值。标有 **只读** 的行不能在这里修改。每行右侧的 **ⓘ** 可查看完整规则、近 7 天唤醒次数、修订号和最后修改者。

| 来源                                         | 选项与效果                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Human 私聊、Bot 私聊、群内提及               | 始终立即唤醒。回合运行中收到消息时，可选择「并入正在运行的回合」（默认）或「排为独立回合」。           |
| 普通群消息                                   | 每条立即唤醒、汇总后唤醒、仅直接 @ 唤醒、静默记录。汇总初始 5 条 / 30 秒；条数 1–100，间隔 1–3600 秒。 |
| Assignment 报告                              | 默认按报告状态或回复请求唤醒，也可每条报告立即唤醒。只影响之后进入收件箱的报告。                       |
| 入群邀请、入群申请/结果、Assignment 生命周期 | 只读。                                                                                                 |

## 修改规则

1. 点击对应来源行。
2. 选择规则；选择汇总时，填写消息条数和间隔秒数。
3. 点击 **保存**。**恢复默认** 会撤销这个来源的修改。

![编辑普通群消息的默认唤醒规则与汇总阈值](/guides/channel-sidebar/17-wake-policy-dialog-zh.webp)

## 在本地群聊中

打开群，在频道侧栏展开 **唤醒策略**。每个成员 Bot 一张卡片：第二行是它在这个群里的规则，已接入的外部平台各占一行。标有 **频道自定义** 的是为这个群单独设置的规则，没有标记时沿用 Bot 自己的默认值。点卡片选择规则和阈值，或点 **恢复继承** 重新使用 Bot 默认值，见 [成员与群管理](/zh/docs/channel-sidebar/groups)。

唤醒策略不改变模型、API Provider 或工作区权限。
