# 外部身份

打开 **Bot 私聊 → Channel sidebar → 外部身份**。外部身份决定这个 Bot 在 Lark / 飞书、Slack、微信等外部平台以谁的身份发言。每个 Bot 每个平台绑定一个身份，其他 Bot 不能借用。绑定身份不会授权任何群或会话，也不会开启收件；这些在[外部连接器](/zh/docs/channel-sidebar/external-connectors)中完成。

![外部身份分区，每个已绑定身份一行](/guides/channel-sidebar/18-external-identities-zh.webp)

## 读懂每一行

| 行                               | 显示与作用                                                                                                                                              |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 每个已绑定身份一行               | 本地显示名称、状态标签（**可用**、**已暂停**、**暂不可用** 或 **需要重新绑定**），以及「平台 · 继承全局默认／自定义」。右侧 Switch 启用或停用这个身份。 |
| **+ 绑定身份**                   | 选择已连接的 **IM账号**，绑定新身份。                                                                                                                   |
| **连接 Lark / 飞书**（配置引导） | 打开 Lark / 飞书分步配置引导。其中的 **定位** 会高亮侧栏中对应的行，必要时自动展开 **外部连接器**。                                                     |
| **IM 管理员配对**                | 显示「N 个待处理」和「已配对 N 人」，点击打开配对审核弹窗；见[连接 Lark / 飞书](/zh/docs/lark-connection)。                                             |
| **Lark 审批通知**                | 显示通知目的地，或 **关闭自动通知**；点击打开审批通知弹窗。                                                                                             |

## 绑定身份

1. 先按对应平台的教程，在 **设置 → IM机器人** 连接应用账号。
2. 点击 **+ 绑定身份**。
3. 在 **IM账号** 中选择已连接的账号。下拉框支持搜索，输入文字即可筛选。
4. 保存。然后到[外部连接器](/zh/docs/channel-sidebar/external-connectors)授权外部会话。

## 编辑、重新连接或解绑

点击身份行，打开 **编辑外部身份**。

1. 修改 **本地显示名称**，或修改 **绑定后的身份默认行为**：继承全局默认，或自定义。
2. 点击 **保存身份**。
3. **重新连接** 会重新验证同一账号与已有授权范围。账号已变更时，需要解绑后重新绑定。
4. **解绑**（红色）需要确认，并列出将失效的此 Bot 已有授权。已收消息和来源历史保留；不会删除共享账号或凭据。
