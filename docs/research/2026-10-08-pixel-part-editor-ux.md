# Pixel-part editor UX — patterns from existing pixel-art editors

Date: 2026-10-08 (Asia/Tokyo). Context: the in-app Custom Part editor for 32×32 chibi bust avatars (`@botharness/pixel-avatar`, BotPixel). Each cell stores a color source (recipe slot such as hair, skin or outfit, or a fixed hex) plus a tone step (about −2..+2). First-version tools: pencil, eraser, flood fill, gradient (stepped tones, ordered dither), noise, left/right mirror, line, rectangle, eyedropper, undo/redo, live 1× preview. Parts export as PNG with embedded part data. Plain PNG import is quantized to fixed colors.

Method: official docs and source repos first. Aseprite docs were read from [aseprite/docs](https://github.com/aseprite/docs), the source of aseprite.org/docs. Piskel, LibreSprite and the Lospec Pixel Editor were read from their GitHub sources. For closed apps I used official docs, store pages and the developers' own sites, reached through search because direct fetches were blocked in this environment. Pixilart has no official help page that I could find. Its claims below come from the editor's own UI strings as shown on pixilart.com, so they are marked **provenance weak**.

## Findings by editor

**Aseprite** (proprietary EULA; source-available for personal builds only, [EULA](https://github.com/aseprite/aseprite/blob/main/EULA.txt)). Tools sit in a vertical tool bar, and a **context bar** above the canvas holds the active tool's options ([context bar](https://www.aseprite.org/docs/context-bar/)). Related tools share a slot. For example, the eyedropper is grouped with the eraser and can also be reached with `Alt`+click ([eyedropper](https://www.aseprite.org/docs/eyedropper/)). Left click paints with the foreground color and right click with the background color, for almost every tool ([drawing](https://www.aseprite.org/docs/drawing/)).

- **Symmetry**: turned on from the View menu, then each axis has its own context-bar toggle, a draggable on-screen axis handle and a "Reset Symmetry to Center" command. The axis may sit in the middle of a pixel ([symmetry](https://www.aseprite.org/docs/symmetry/)).
- **Gradient**: this is a fill. It has the paint bucket's region options (tolerance, contiguous, 4- or 8-connectivity, stop at grid). It adds linear or radial modes and dithering choices of none or Bayer 2×2, 4×4 or 8×8 ([context bar › gradient](https://www.aseprite.org/docs/context-bar/#gradient-tool)).
- **Shading ink**: you choose a run of palette colors as a ramp. Left click then moves each painted pixel one step one way along the ramp, and right click moves it the other way ([shading](https://www.aseprite.org/docs/shading/)). This is the closest existing analogue to our tone steps.
- **Indexed mode**: each pixel refers to a palette entry, so editing the entry recolors every pixel that uses it ([color mode](https://www.aseprite.org/docs/color-mode/)). In indexed mode the color bar offers only palette colors. In RGB mode, a warning icon offers to add an off-palette color to the palette ([color bar](https://www.aseprite.org/docs/color-bar/)).
- **Quantization**: RGB→indexed conversion uses a dithering algorithm (none, ordered or old) and a matrix (bayer2x2/4x4/8x8) ([CLI](https://www.aseprite.org/docs/cli/#dithering-algorithm)).
- **Canvas helpers**: a pixel-perfect stroke toggle ([context bar](https://www.aseprite.org/docs/context-bar/#pixel-perfect-mode)), a separate visible pixel grid ([preferences › grid](https://www.aseprite.org/docs/preferences/#grid)), number keys 1–6 for 100–3200% zoom ([zoom](https://www.aseprite.org/docs/zoom/)), and a small real-time Preview window on `F7` ([preview window](https://www.aseprite.org/docs/preview-window/)). Pinch zoom and two-finger pan work on touch devices ([sprite editor](https://www.aseprite.org/docs/sprite-editor/)).
- **Undo**: each action is one state, Ctrl+Z/Ctrl+Y step through them, and a history list lets you jump to any state. Non-linear history is optional ([undo history](https://www.aseprite.org/docs/undo-history/)).

**LibreSprite** (GPL-2.0). A fork of the last GPL Aseprite commit from 2016 ([README](https://github.com/LibreSprite/LibreSprite)). Its `data/gui.xml` shows the grouped tool model in its plainest form ([gui.xml](https://github.com/LibreSprite/LibreSprite/blob/master/data/gui.xml)):

- Each slot is a named group: pencil plus spray, eraser, eyedropper, paint bucket, shapes, and effects (blur and **jumble**).
- Each tool sets separate `ink_left` and `ink_right`. For the eraser, the left button erases and the right button replaces the foreground color with the background color.
- Jumble is a random-scramble brush, which is the nearest built-in analogue to our noise tool.

**Piskel** (Apache-2.0, [repo](https://github.com/piskelapp/piskel)). Web, beginner-oriented, with a single tool column in the order pen, mirror pen, bucket, color swap, eraser, stroke, rectangle, circle, move, selections, lighten, dithering, picker ([ToolController.js](https://github.com/piskelapp/piskel/blob/master/src/js/controller/ToolController.js)).

- **Mirror pen**: symmetry is a separate pen, not a global mode. Its axis is fixed at the canvas center. `Ctrl` switches to the horizontal axis and `Shift` mirrors on both axes. Odd pen sizes get a 1-pixel offset so the mirror stays exact ([VerticalMirrorPen.js](https://github.com/piskelapp/piskel/blob/master/src/js/tools/drawing/VerticalMirrorPen.js)).
- **Dithering**: a brush that paints a `(col+row)%2` checkerboard of the primary and secondary colors. Right click swaps the phase ([DitheringTool.js](https://github.com/piskelapp/piskel/blob/master/src/js/tools/drawing/DitheringTool.js)).
- **Lighten**: `Ctrl` darkens, and `Shift` applies only once per pixel per stroke, so going over the same pixel again does not keep shifting it ([Lighten.js](https://github.com/piskelapp/piskel/blob/master/src/js/tools/drawing/Lighten.js)).
- **Preview modes**: "original" (1×), "best" (integer fit) and "full" ([PreviewController.js](https://github.com/piskelapp/piskel/blob/master/src/js/controller/preview/PreviewController.js)).
- **Palettes**: an automatic "Current colors" palette lists the colors already in the sprite ([CurrentColorsPalette.js](https://github.com/piskelapp/piskel/blob/master/src/js/service/palette/CurrentColorsPalette.js)). Importing a palette from an image is refused with "Too many colors" above a maximum ([PaletteImageReader.js](https://github.com/piskelapp/piskel/blob/master/src/js/service/palette/reader/PaletteImageReader.js)).
- **Modifier hints**: each tool's tooltip lists its modifier keys.

**Lospec Pixel Editor** (GPL-3.0, deprecated and unmaintained, [repo](https://github.com/lospec/pixel-editor)).

- It starts in **Basic mode**, which has no layers. Advanced mode adds layers and the full color picker, and switching back flattens the layers after a confirmation ([EditorState.js](https://github.com/lospec/pixel-editor/blob/master/js/EditorState.js)).
- New documents come from presets of size plus palette (Game Boy Color, PICO-8, C64) ([PresetModule.js](https://github.com/lospec/pixel-editor/blob/master/js/PresetModule.js)).
- Editing a palette swatch runs `replaceAllOfColor` across the canvas. Deleting a swatch maps its pixels to the lightest remaining color, and duplicate swatches trigger a shake warning ([ColorModule.js](https://github.com/lospec/pixel-editor/blob/master/js/ColorModule.js)).
- The palette block supports drag-selecting a ramp ([PaletteBlock.js](https://github.com/lospec/pixel-editor/blob/master/js/PaletteBlock.js)).
- The README's to-do list names mobile as the gap: touch equivalents for mouse clicks, portrait layout and popups.

**Pixquare** (proprietary, iPad/iPhone, [docs](https://docs.pixquare.art/)).

- **Gestures**: two-finger tap undoes, two-finger hold undoes rapidly, three-finger tap redoes and three-finger hold redoes rapidly ([gestures](https://docs.pixquare.art/interface-and-gestures/gestures-and-quick-actions)). An "only draw with pencil" setting reserves fingers for navigation so palms don't leave stray pixels ([drawing settings](https://docs.pixquare.art/settings/drawing)).
- **Symmetry**: off by default and enabled in Settings. It is built from line groups around a shared center, each line with a drag knob, a mirror/rotate mode and reset-to-center ([symmetry](https://docs.pixquare.art/additional-features/symmetry)).
- **Gradient**: lives in the bucket and fills linear or radial with optional dithering. **In indexed mode it interpolates palette indices, not RGB** ([color bucket](https://docs.pixquare.art/tools/color-bucket)).
- **Shading**: you choose a ramp by tapping its two ends. Pixels in the ramp move to the neighboring color, pixels not in the ramp are ignored, and tapping the ramp flips the direction. It applies to the brush, line, shape and bucket ([shading](https://docs.pixquare.art/palette/shading)).
- **Ramp generator**: builds a ramp between two colors, with a step count and RGB or HSV interpolation ([gradient generator](https://docs.pixquare.art/palette/gradient-generator)).
- **Color reduction and remap**: color reduction trims only the palette. Color remap is the separate step that recolors the artwork ([reduction](https://docs.pixquare.art/palette/color-reduction), [remap](https://docs.pixquare.art/tools/additional-tools/color-remap)).
- **Palette import**: a palette can be imported from an image, keeping the first 254 colors ([importing palettes](https://docs.pixquare.art/palette/importing-palettes)).
- **Lines**: the line tool is always pixel-perfect ([line](https://docs.pixquare.art/tools/line)).

**dotpict / ドットピクト！** (proprietary, iOS/Android, [App Store JP](https://apps.apple.com/jp/app/id995653343), [developer site](https://dotpict.com/)). The defining pattern is that **the cursor is separate from the draw button**:

- Dragging a finger moves an offset cursor and draws nothing. Pressing PUSH places a dot, and holding PUSH while moving draws a line. Because of this, the finger never hides the target cell (App Store copy).
- Direct-touch "pen mode" was added later as a setting ([developer history, note](https://note.com/chocomelon/n/ne5212bd134cb)).
- Work is autosaved, and palettes come ready-made so beginners don't have to choose colors. Palettes can be shared and downloaded, and new canvases start at fixed small sizes such as 16/24/32 (App Store copy).

**EDGE / Edge3** (Takabo Soft, proprietary).

- Gradients combine color interpolation with dithering. A brush effect paints by shifting colors within a chosen palette range, which the catalog describes as useful for tonal work ([feature catalog](https://edge3.takabosoft.com/en/features/)).
- Palettes are indexed and kept in tabs. Making alternate palettes such as "2P colors" is a headline feature ([home](https://edge3.takabosoft.com/en/)). This is the same idea as recoloring a part through its recipe slots.
- The older iOS app EDGE touch exists ([App Store](https://apps.apple.com/us/app/edge-touch-pixel-art-tool/id329021851)), but its dither-gradient claims could only be confirmed from reviews.

**Pixilart** (proprietary, web and mobile, [mobile page](https://www.pixilart.com/mobile), [App Store](https://apps.apple.com/us/app/pixilart/id1440580518)). **Provenance weak**: these come from the editor's UI strings ([editor](https://www.pixilart.com/draw)).

- The menu offers Mirror X and Mirror Y.
- "Global Dithering" turns on dithering for every tool.
- "Random Colors" picks a random palette color for each pixel, a noise-like brush.
- Pixel Perfect and lighten/darken both state that they don't work with mirror and need pixel size 1. That tool-mode conflict is worth avoiding.

**Picrew** (proprietary). Neither players nor creators get a drawing tool. Creators upload pre-drawn PNGs, one for each item × layer × color ([upload](https://support.picrew.me/en/creator_functions/item_image_upload)), and each part has up to 16 colors ([add color](https://support.picrew.me/en/creator_functions/color_add)). "Color Link" keeps related parts such as front and back hair the same color ([color link](https://support.picrew.me/en/creator_functions/color_link_settings)). Our slot-plus-tone cells give that recolor behavior at runtime without per-color uploads.

## Cross-cutting patterns

1. **Recoloring through references.** Aseprite indexed mode, Lospec `replaceAllOfColor`, EDGE "2P colors" and Picrew Color Link all change the color by editing what pixels refer to, not the pixels themselves. Our color source is that reference, so the UI should present color slots, not hex values.
2. **Tone as a direction along a ramp.** Aseprite shading, Pixquare shading, EDGE range shifting and Piskel lighten all step colors along a ramp. Pixquare and Piskel add two safeguards: pixels outside the ramp are left alone, and each pixel is changed at most once per stroke.
3. **Gradient as a bounded fill with ordered dither in index space.** Aseprite and Pixquare both work this way, and Pixquare interpolates indices. Bayer 2×2/4×4/8×8 is the standard menu.
4. **Symmetry is visible, and its axis can be centered.** Aseprite, Pixquare and Piskel all show the axis or center it. Odd and even widths need explicit pixel-center handling (Aseprite mid-pixel axis, Piskel pen-size offset).
5. **Touch needs a separate drawing input.** dotpict uses an offset cursor plus a PUSH button, and Pixquare uses pencil-only drawing with finger gestures. Two-finger tap for undo and three-finger tap for redo is an established iPad convention.
6. **Beginner success comes from constraints.** Examples: fixed small canvases and ready palettes (dotpict, Lospec presets), a layer-free Basic mode (Lospec), and 16 colors per part (Picrew).

## Recommendations for the Custom Part editor

| Tool / concern   | Recommendation (source pattern)                                                                                                                                                                                                                                                                                                                                                         |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tool palette     | Use one short column grouped as draw (pencil, eraser, eyedropper), fill (bucket, gradient), shape (line, rect) and texture (noise), with a per-tool options strip like Aseprite's context bar. Put modifier hints in tooltips (Piskel).                                                                                                                                                 |
| Color picker     | Use a grid of rows by recipe slot (hair, skin, outfit, …) and columns by tone −2..+2, plus a short "fixed colors" row. An off-slot hex goes into the fixed row explicitly (Aseprite warning icon). Show a "used in this part" strip (Piskel Current colors).                                                                                                                            |
| Pencil / eraser  | Left button paints and right button erases (LibreSprite `ink_left`/`ink_right`). An optional **Shade** modifier moves an existing cell's tone ±1 and leaves its source alone. It skips empty cells and changes each cell once per stroke (Aseprite shading, Pixquare, Piskel Lighten Shift). Default pixel-perfect on for 1px strokes.                                                  |
| Flood fill       | Use 4-connectivity by default and match on source plus tone exactly, so there is no tolerance slider (Aseprite bucket options, simplified).                                                                                                                                                                                                                                             |
| Gradient         | Drag start→end inside the fill region, using one color source. Interpolate **tone steps**, not RGB (Pixquare indexed gradient), and dither between neighboring steps with Bayer 4×4 by default and an option for 2×2 (Aseprite). Make it linear only in v1. Radial is an Aseprite and Pixquare extra.                                                                                   |
| Noise            | Apply a seeded ±1 tone jitter that writes into the cells. It touches only cells that already have a source (Pixquare shading ignores pixels off the ramp) and clamps to the ramp. Offer amount and re-roll controls, and store the seed so redo is repeatable (Pixilart Random Colors and LibreSprite Jumble, made safe).                                                               |
| Mirror           | Use one toggle with a visible axis locked to the avatar centerline, between columns 15 and 16 since figure `C = 16`. It applies to **every** tool, including fill, gradient, noise, line, rect and eraser, with no "doesn't work with mirror" exceptions (Pixilart's anti-pattern). If the axis ever falls on a pixel center, handle it explicitly (Aseprite mid-pixel, Piskel offset). |
| Line / rectangle | Show a live preview while dragging and commit on release. Shift snaps lines to 0°, 45° and 90° and makes rectangles square (Piskel). Offer outline and filled variants, and keep lines always pixel-perfect (Pixquare).                                                                                                                                                                 |
| Eyedropper       | Use `Alt`+click or long-press as a temporary pick (Aseprite). It picks **source plus tone**, not hex. Sample the part first and fall back to the avatar's slot under the cursor (Aseprite sample-layer options).                                                                                                                                                                        |
| Undo / redo      | Make one stroke or one fill a single entry with linear history and Ctrl+Z / Ctrl+Shift+Z (Aseprite). On touch, two-finger tap undoes and three-finger tap redoes (Pixquare).                                                                                                                                                                                                            |
| Canvas & preview | Use an integer-zoom editing canvas with a pixel grid, showing the slot's bounds and the avatar dimmed underneath as a reference. Keep a fixed **1× preview on the real avatar** plus a 2× or integer "best" preview (Piskel original/best, Aseprite F7).                                                                                                                                |
| Mobile           | Give an offset-cursor-plus-PUSH mode as an option for phones (dotpict), with pinch-zoom and two-finger pan (Aseprite, Pixquare). Avoid hover-only UI (Lospec mobile gaps).                                                                                                                                                                                                              |
| PNG import       | Quantize to the nearest color with **no dithering** by default, because dithering at 32px reads as noise. Cap the color count and show the count before accepting (Piskel "Too many colors", Pixquare first-254). Keep "reduce palette" separate from "remap pixels" (Pixquare). Use an alpha threshold so cells are binary.                                                            |
| PNG export       | Write the 1× PNG plus part data in a PNG text chunk ([PNG iTXt](https://www.w3.org/TR/png-3/#11iTXt)), so a plain viewer still shows the art.                                                                                                                                                                                                                                           |
| Beginners        | Use fixed slot bounds, the slot-and-tone palette instead of a free color wheel, autosave of drafts (dotpict), and no layers (Lospec Basic mode).                                                                                                                                                                                                                                        |

**Licenses.** Aseprite is under an EULA that forbids redistribution, so don't copy its code or icons. The aseprite/docs repo had no license file in my checkout, so don't copy its text or images either. LibreSprite is GPL-2.0 and Lospec is GPL-3.0, so copying their code would force our package (MIT) to become GPL. Piskel is Apache-2.0, which is permissive but needs NOTICE attribution if code is copied. Pixquare, dotpict, Edge3, Pixilart and Picrew are proprietary. We use only their behavior as reference and implement our own code and assets. Bayer matrices are standard math and fine to write ourselves.
