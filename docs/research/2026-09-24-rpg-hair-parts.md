# RPG / 角色创建器的头发分件、拼接与参数调研 — hair as assembled parts

## 0. 元信息

| 项       | 内容                                                                                                                                                                                                                                                              |

| 问题     | RPG/游戏角色创建器如何把头发定义、切分、允许多片拼装，使结果读起来平滑、立体？（部位分类、无缝拼接、后脑/3D 体量、每片暴露的参数、一手来源实例）                                                                                                                          |
| 日期     | 2026-09-24                                                                                                                                                                                                                                                        |

**一句话结论**：一手系统分成两档——**整发预设档**（WoW/FFXIV/GW2/Sims 4/RPM：整头一个 hairstyle + 一个发色）与**分件组装档**（VRoid 9 类发件、Reallusion HairStyle→HairGroup→HairElement、BDO 前/侧/顶三段长度 + 三段染色）；**防缝的共识做法**是「头皮底座层（base hair / scalp backdrop / textured head）+ 内→外分层、根部插进底座不悬空 + 同向梳理 + 透明层手工排序」；后脑发必须是**真 3D 网格/整圈底座**，靠 UI 可旋转预览暴露。对 2D SVG 原型：按 VRoid 词表建 6–8 个 patch，底座压在最下，前/侧发件可单侧，长度/卷曲/分缝/分区染色是第一批该暴露的参数。

## 1. Region/part taxonomy（部位/分件词表）

- **VRoid Studio（官方 Help，最显式的分件系统）——髪アイテム 9 类**：`髪セット`（整套）、`前髪`（front bangs，部件件）、`後髪`（back hair，部件件）、`一体髪`（one-piece，无前后之分、盖满全头）、`つけ髪`（附加件，如马尾/发髻类）、`横髪`（side hair）、`アホ毛`（ahoge 呆毛）、`はね毛`（swoosh/flick 翘发）、`ベースヘアー`（base hair：**隠す頭皮の下地**，盖住头皮的底层）。规则：`前髪`/`後髪` **不能与 `一体髪` 组合**；`髪セット` 是把部件成组选择。—— https://vroid.pixiv.help/hc/ja/articles/900005965586 ；EN 同页 https://vroid.pixiv.help/hc/en-us/articles/900005965586-How-to-Apply-Hairstyle-Items
- **VRoid 编辑器内以 hair group 为单位组织**，左侧类别图标切到某一发件类别后，按 group 追加/编辑（手描き=freehand、プロシージャル=procedural 两种生成器）。—— https://vroid.pixiv.help/hc/en-us/articles/900005678786-How-do-I-customize-hairstyles
- **Reallusion Character Creator 4（官方 Manual）——三级层次**：`HairStyle`（整发型，由 hair + eyebrow + beard **groups** 组成）→ `HairGroup`（可单独替换 Hair / Eyebrows / Beard）→ `HairElement`（构成 Hair 与 Beard group 的元素级模板）。—— https://manual.reallusion.com/character-creator-4/Content/ENU/4.0/08_Hair/Smart-Hair-Content-Structure.htm ；Element 系统页（图示）https://manual.reallusion.com/character-creator-4/Content/ENU/4.0/08_Hair/Hair-Element-System.htm
- **CC 的网格级二分**：hair mesh = **scalp（头皮底座）+ hair strips（发条）**，两套材质/UV，命名 `Hair_Scalp` / `Hair_Strips`，合并后必须叫 `RL_HairMesh` 才被 CC 识别；导入时按类别归档 **Hair / Eyebrows / Beard**（Beard 与 Scalp Hair、Eyebrows 分属不同 conformation 方式）。—— https://wiki.reallusion.com/Content_Dev:CC_Hair_Creation_Guide ； https://wiki.reallusion.com/Content_Dev:CC_3.4_Hair_Mesh_Production
- **Black Desert（官方 Adventurer's Guide）——三段长度按头皮区域命名**：`Length 1` = **front hair**（前发/刘海长）、`Length 2` = **side hair**（侧发长）、`Length 3` = **upper/top hair**（头顶发长，部分短发禁用）；卷曲拆 `Curl strength`（卷度强度/量感）与 `Curl level`（卷的个数）。**面部毛发**单列：beard、mustache、**sideburns**、brow、eyebrows。—— https://www.naeu.playblackdesert.com/en-us/Wiki?wikiNo=5
- **WoW（Blizzard 官方工程文）**：Shadowlands 把旧「5/8 个通用槽」重构为**每个 feature 相互独立**（eyes / face / beard / moustache…），迁移规则里明确 **Human beard 被拆成 beard、mustache、sideburns 三个独立项**。—— https://news.blizzard.com/en-us/article/23564386/engineers-workshop-enhancing-character-customization
- **WoW 角色创建 UI 分类**：全部选项归入 **3 个类别图标**，发型从第二类移到**第一类（与脸部选项同组）**，因「换发型通常是玩家做的第一件事」。—— http://worldofwarcraft.blizzard.com/en-us/news/23737992
- **City of Heroes（官方论坛存档，Developers' Corner 官方串）**：头部是分槽位的 costume 结构，发件出现在 `Head Detail 1` 等头部子槽；官方补丁文提到「若干女性发型被调整以更好地贴合」「新增 Ponytails Fat 发型」——即**发型是头部槽里整件可选项**，与 mask/helmet/glasses 并列。—— https://forumarchive.cityofheroes.dev/topic/116949 （官方创建流程页描述「head：hairstyles, masks, helmets, glasses…」并给出旋转箭头：http://www.cityofheroes.ca/game_info/welcome_to_city_of_heroes/creating_a_hero.html ，**provenance 弱**：cityofheroes.ca 为官方门户域名存续页，建议引用时加注）
- **Ready Player Me（官方 Docs）**：`HairStyle` 是与 `EyebrowStyle`/`BeardStyle` 并列的独立 asset type（Head Customization 类：LipShape, NoseShape, FaceShape, EyebrowStyle, EyeShape, BeardStyle, HairStyle）；avatar 上 `hairStyle` 与 `hairColor` 是**两个独立字段**。—— https://docs.readyplayer.me/ready-player-me/integration-guides/unity/avatar-creator/build-your-own-avatar-creator/elements/asset-selection-element ； https://docs.readyplayer.me/ready-player-me/integration-guides/api-integration/custom-avatar-creator
- **Roblox（官方 Creator Docs）**：hair 属于 **face accessory**（与 eyebrows/eyebrows/glasses/facial hair 同类）；随身体上传时命名约定含 `HairAccessory`；多部件（如眉毛）**建模拟合完成后合并为单一 mesh**。—— https://create.roblox.com/docs/art/characters/facial-animation/create-face-accessories
- **FFXIV（官方 patch notes）**：发型以**整只 hairstyle 选项**供给与迭代（"New hairstyle options have been added for Viera/Hrothgar"、"New hairstyles have been added"），**没有**部位分件；改发走 aesthetician/Fantasia 整体编辑。—— https://na.finalfantasyxiv.com/lodestone/topics/detail/c807875c5f8f7529887c86d2955f709eae0231ef ； https://na.finalfantasyxiv.com/lodestone/topics/detail/9beb8a7b5c46944cd80ed92b2b8e972395fbea80
- **GW2（ArenaNet 托管官方 wiki）**：创建期物理外观 = 预设 + 少量 slider；`Head Options` 下 hairstyle / face（部分种族另有 facial hair）分列；改发型靠 `Self-Style Hair Kit`（一次性改 hair style、hair color、horns、facial hair）。—— https://wiki.guildwars2.com/wiki/Physical_appearance ； https://wiki.guildwars2.com/wiki/Self-Style_Hair_Kit ； https://wiki.guildwars2.com/wiki/Character_creation
- **Sims 4（EA 官方）**：发型是 CAS 里的整件资产（news 反复以「new hairstyle(s)」交付），**颜色走 swatch**（官方更新文：「Hairstyles … now show all newly added hair swatches」）；官方访谈确认 swatch 可烤入**发根略深**的双色设计（Bantu Knots：「rich colored hair swatches have slightly darker roots」）。Face 面板含 hair styles/colors（EA 手册）。—— https://www.ea.com/en-au/games/the-sims/news/update-07-18-2023 ； https://www.ea.com/games/the-sims/the-sims-4/news/new-bantu-knots-and-two-strand-twist-hairstyles-for-the-sims-4 ； https://eaassets-a.akamaihd.net/eahelp/manuals/the-sims-4-ps4-ukanz.pdf
- **VRM 规范（first-party spec）**：**没有头发部位概念**。头发只是普通 mesh；`firstPerson.meshAnnotations` 只按「是否含 Head 骨权重」把 mesh 分成 first/third-person 可见性（`auto` 算法），明确举例 face/eyes/**head/hair**/hat 属 `thirdPersonOnly`；摆动靠 spring bone（VRM 0.x 描述 secondaryAnimation 用于 "string-like objects such as tails and hairs"）。—— https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/firstPerson.md ； https://dwango.github.io/en/vrm/vrm_spec/
- **一手演讲里的部位词表（provenance 弱：第三方镜像承载的一手讲稿）**：Tomb Raider/TressFX 制作中 splines 按 **4 组组织：bangs、cap、fringe、ponytail**（AMD/Confetti/Crystal Dynamics 2013 讲稿，镜像：https://www.slideshare.net/slideshow/hair-intombraider-final/20208628 ）；Eidos-Montréal GDC 2015「PureHair」把资产分成三层：**Textured head（皮肤↔头发过渡底层）/ Hair meshes（卡片）/ Hair strands**，并写明 textured head 的用途是「smooth transition between the skin and other hair assets、fills any gap that could exist in other hair assets」（讲稿镜像 PDF：https://cdn.wccftech.com/wp-content/uploads/2015/03/Augmented-Hair-in-Deus-Ex-Universe-Projects-TressFX-3-0.pdf ，talk 描述见 GDC 议程转述 https://wccftech.com/dawn-engine-slide-showcasing-amds-tressfx-30/ ——**一手 slides、非官方 host**）。
- **缺口（明确未验证）**：没有任何一手来源把「前刘海」再拆成「左/右可单独开关的 one-side 刘海」作为**命名参数**暴露；单侧效果在一手系统里靠「该侧单独放一个发件组 + 不镜像 / Flip 只镜像」实现（VRoid），inZOI 的 Symmetry/Individual Edit 切换目前只见于玩家站（Game8，**未验证**：https://game8.co/games/inZOI/archives/504669 ）；Krafton 一手仅确认「adjust the length and style of hair」+ 全域 color picker（ https://www.krafton.com/en/news/press/krafton-launches-inzoi-character-studio-on-steam/ ； https://playinzoi.com/en/news/7619 ）。

## 2. Assembly & smoothness（拼装与无缝）

- **底座/头皮层是共识**：VRoid `ベースヘアー` = 「頭皮を隠す下地部分」（https://vroid.pixiv.help/hc/ja/articles/900005965586 ）；CC 官方：scalp **先从头部网格复制并外扩**、「The scalp serves as a backdrop for the hair」，且 scalp 贴图应比头更深、hair 卡片**必须插进 scalp、不许悬空**（"Always plug the hair strip into the scalp mesh, do not 'float' the strips"；也不许直接怼穿 scalp）。—— https://wiki.reallusion.com/Content_Dev:CC_3.4_Hair_Mesh_Production ； https://www.reallusion.com/character-creator/CC_Asset_Developer_Guide.pdf （§6 Conforming Hair）
- **内→外分层与层序**：CC 官方工作流「从 scalp 开始、**一层一层由内向外**附加，以避免 DX9 下的 opacity layer disorder（DX11+ 无此问题）」；示例发型做 **6 层**（inner thicker、outer thinner strips），层间留小缝供布料碰撞，根部多分段以支持圆润弯折。—— https://www.reallusion.com/character-creator/CC_Asset_Developer_Guide.pdf
- **条与条留缝、UV/材质分工**：hair strips 材质含 diffuse/bump/specular/**opacity**/RGB mask/physics map；scalp 材质少 physics；scalp **不得**挂 soft-cloth、UV 需均匀；条间留 gap 防动态碰撞互穿。——同上 PDF； https://wiki.reallusion.com/Content_Dev:CC_3.4_Hair_Specification_and_Submission （scalp 与 hair cards 两套纹理：ID/Root/AO/Depth/**Flow** 等）
- **发际线贴合（防穿模缝）**：CC 4.1 官方「Conforming Hair on Head」——发际线处 hair 不随表情动会导致 mesh penetration，工具用 Hair Line 预设选取顶点 + Distance/Blend Range 把发际顶点贴回头皮。—— https://manual.reallusion.com/Character-Creator-4/Content/ENU/4.1/08_Hair/Conforming-Hair-on-Head.htm
- **同向梳理/方向连续性**：VRoid 官方发件制作访谈（VRoid STYLE）给出拼装口诀——**「从各个角度看剪影是否崩」**、**「头发之间有缝隙时不要用一个 guide 硬凑，新开 guide 填缝」**、**「从下层往上堆叠」**、前发常拆成 ~3 个部件再各放大股+细发。—— https://vroid.com/news/202012201700
- **分缝（parting）作为跨片方向场**：VRoid 官方把 parting 做成 procedural 参数：`分け目（長さ）`、`分け目（横髪の量）`、`分工目（横髪のまとまり）`，即分缝线的深度、把多少发量拨向侧发、侧发向前收拢多少——一条分缝参数同时约束多股发的走向。—— https://vroid.pixiv.help/hc/ja/articles/360013209794
- **透明卡的排序是「平滑感」的硬约束**：Unity HDRP 官方——hair shader 用 hair cards 分层，**「If you use semi-transparent hair cards, you must manually sort them so that they're in back-to-front order from every viewing direction.」**（每个视角都要背→正面排序，否则接缝/错序可见）。—— https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.4/manual/understand-hair-and-fur.html
- **拼合为单 mesh 再入引擎**：CC 官方把 scalp+strips **combine 成一个 RL_HairMesh** 再导入；Roblox 官方要求 face accessory 多件拟合后 **combine 成 single mesh**，并尽量让 accessory 边缘对齐**头部拓扑 edge/vertex** 以改善形变贴合。—— https://wiki.reallusion.com/Content_Dev:CC_Hair_Creation_Guide ； https://create.roblox.com/docs/art/characters/facial-animation/create-face-accessories
- **clump/多卡成团制造体积而非硬接缝**：Epic 官方 Hair Card Generator——`Multi-Card Clumps` = **每 strand clump 3 张 card** 来给体积感；`Card Group` 可按「hairline 短发、blockout/mid/top layer、flyaways」分组生成；`Num Flyaways` 单独控细节飞发。—— https://dev.epicgames.com/documentation/unreal-engine/hair-card-generator-for-grooms-in-unreal-engine
- **发色分区染减少「两片色差」感**：CC Appearance Editor 用 **RGB mask 把发分成 Base / Primary(R) / Secondary(G) / Tertiary(B) 四区**分别上色（至多四区），使单 mesh 内多区可控而不必拆材质；BDO 官方把同一发型的色拆 **Base / Hair end / Inner hair** 三区（各控色、染色范围、内层）+ 光泽。—— https://www.reallusion.com/character-creator/CC_Asset_Developer_Guide.pdf ； https://www.naeu.playblackdesert.com/en-us/Wiki?wikiNo=5
- **头↔发过渡层**：GDC 2015 PureHair（一手 slides、镜像 host）明确 textured head 层的职责就是「皮肤与其它 hair 资产之间的 smooth transition、补任何其它发件留下的 gap」（https://cdn.wccftech.com/wp-content/uploads/2015/03/Augmented-Hair-in-Deus-Ex-Universe-Projects-TressFX-3-0.pdf ）。CC 侧对应物是 scalp 贴图负责「delineate the hairline」。—— http://wiki.reallusion.com/Content_Dev:CC_3.4_Hair_Creation_Introduction

## 3. 3D volume & back-of-head（后脑与体量）

- **真 3D、整圈覆盖**：VRoid 的 `ベースヘアー` 是盖住**头皮**的整圈下地（不分前后），`後髪` 是独立可选件、`一体髪` 明确「頭全体を覆う」——后脑发不是折叠面片，而是底座+后发件/整发网格。—— https://vroid.pixiv.help/hc/ja/articles/900005965586
- **CC：hair 是 conforming 网格**，两种体系——**Conforming Hair**（贴合头形、可用 soft-cloth）与 **Spring Hair**（自带骨、走 spring bone），全部是 geometry（iClone 无实时毛发系统）；绑定从 `CC_Base_Hair` 起、短发可整只绑 head 骨。网格天然 360° 存在。—— https://wiki.reallusion.com/Content_Dev:CC_Hair_Creation_Guide ； https://www.reallusion.com/character-creator/CC_Asset_Developer_Guide.pdf
- **引擎层的三档表示**（决定后脑剪影）：Epic 官方 Groom 资产在**同一 asset/LOD 里可切 Strands / Cards / Meshes** 三种几何（LOD panel 的 Geometry Type），strand 工作流渲染「hundreds of thousands (or more) photoreal hairs」，并可程序化从 strands 生成 cards。—— https://docs.unrealengine.com/4.27/en-US/WorkingWithContent/Hair/GroomAssetEditor/ ； https://docs.unrealengine.com/4.27/en-US/WorkingWithContent/Hair/
- **Unity 官方两档**：HDRP Hair Master Stack 的 Geometry Type = **Cards**（高分辨率发纹理贴在简化几何上）或 **Strands**（管状/带状单根），cards 配 Approximate(Kajiya-Kay) 或 Physical(Marschner)，strands 仅 Physical；Unity 官方 strand 系统包（Enemies 同款）支持 Alembic groom 导入 + **在 mesh 上 scatter 程序化生成**、参数化 length/curl。—— https://docs.unity3d.com/Packages/com.unity.render-pipelines.high-definition@17.4/manual/hair-master-stack-reference.html ； https://github.com/Unity-Technologies/com.unity.demoteam.hair
- **卡片 vs 条的取舍（一手）**：Frostbite SIGGRAPH 2019 讲稿（EA 一手内容）总结行业现状——游戏通常用 **hair cards 或 shells**（多根纤维 clump 成 2D strip），由工具+手工生成、耗时且限制发型多样性；strands 换来更真实的物理/渲染与更易 LOD，但成本更高。—— https://advances.realtimerendering.com/s2019/hair_presentation_final.pdf
- **分层堆出后脑体积（创作法）**：VRoid 官方创作者访谈——「ボリュームのある跳ね髪…下層から積み上げるように細かくガイドを分けていく」「从各个角度确认剪影不崩」；即后脑体量=多 guide 分层而非单片面。—— https://vroid.com/news/202012201700
- **角色创建 UI 如何暴露「后脑」**（一手）：
  - **City of Heroes 官方创建页**：costume screen「**rotate the figure at will by clicking on the curved arrows**」，可 zoom 到 head/torso——（**provenance 弱**，见 §1 cityofheroes.ca 注）http://www.cityofheroes.ca/game_info/welcome_to_city_of_heroes/creating_a_hero.html
  - **BDO 官方 Beauty Salon**：`Front view` 开关（关掉则脸/眼跟随光标）、**`UI Toggle` 收起 UI 以便「better view of the customized character」**、截图、**按部件（hair/face…）的 Undo/Redo edit history**、Beauty Album（导入他人整套外观）。—— https://www.naeu.playblackdesert.com/en-us/Wiki?wikiNo=5
  - **WoW 官方 UI 设计文**：hover 即时预览选项、多列下拉带名字+色板、3 类图标；随机生成时**禁用遮脸选项**（tattoo/warpaint/headdress）以保脸部可读。—— http://worldofwarcraft.blizzard.com/en-us/news/23737992
  - **FFXIV**：创建/Fantasia 编辑在官方支持文里确认为同一 character creation screen（ https://support.eu.square-enix.com/faqarticle.php?id=5383&kid=78772&la=2&sc=0 ）；**「创建界面可自由旋转看后脑」未在一手页面验证（未验证）**。
  - **Sims 4 CAS 旋转**：**未找到一手页面，未验证**（仅 EA 手册确认 Face 面板含 hair styles/colors，https://eaassets-a.akamaihd.net/eahelp/manuals/the-sims-4-ps4-ukanz.pdf ）。
- **VRM/一渲三的遮挡处理**：VRM 用 meshAnnotations 在**第一人称**主动隐藏 head/hair（防挡视野），第三人称照常渲染——即「后脑发在第三人称始终在、只在 FP 视角按 mesh 隐藏」。—— https://github.com/vrm-c/vrm-specification/blob/master/specification/VRMC_vrm-1.0/firstPerson.md

## Implications for a 2D-svg avatar prototype（≤10）

1. **Patch 词表直接抄 VRoid 9 类裁到 6–8 片**：`base`（头皮底座，最底层）、`back`（后发/一体后片）、`side-L`/`side-R`（可单侧）、`bangs`（前刘海，可拆 2–3 子片）、`accent`（呆毛/翘发）、可选 `attachment`（马尾/发髻=つけ髪类）。
2. **层序固定为 base → back → sides → bangs → accent**（Reallusion「由内向外、根部插进底座」的 2D 等价）；每片形状**根部压进 base 内 2–4px**，不出现悬空边。
3. **共享分缝参数**：一个 parting（`offset`, `depth`, `side-sweep`）同时驱动 bangs 分叉与 sides 起始角，保证跨片方向连续（VRoid 分け目三参数的简化）。
4. **缝处理**：相邻 patch 重叠区用同色+同向高光条带；SVG 里等价于「back-to-front 排序」——固定 paint-order（base 最先），禁止后层半透明盖前层（Unity 排序规则的静态版）。
5. **必做 back 片并提供旋转/背面视图**：base 是整圈（BDO `UI Toggle`+CoH 旋转箭头思路：一键「收 UI/转 180°」看后脑），否则侧面/背面暴露秃头。
6. **第一批参数**（对齐 BDO+VRoid 交集）：每片 `visible`、`length`（分 front/side/top 三档）、`curl/wave`（strength+count 两档）、`parting`、`color`（global + optional tips/roots 两区色，Sims swatch/BDO 三区的 2D 子集）、`side: left|right|both`。
7. **不做 per-strand 密度**（2D 用 2–3 条装饰性 strand 线即可）；如需密度感，抄 Epic「clump」思路在单片内画 3 股分缝高光而非加片数。
8. **配件互斥规则抄 VRoid/RPM**：`一体式整发` 与 `前+后分件` 二选一；`headwear` 选中即隐藏 bangs/back（RPM headwear-replaces-hair 防穿插）。
9. **发际线过渡**：base 上缘画深半档+柔边（PureHair textured head / CC scalp-darker 的 2D 版），遮 bangs 根部与头皮的硬接缝。
10. **导出即所见**：hidden 片不进 SVG 输出（VRoid 导出尊重 Toggle Visibility），色区用 `currentColor`/CSS 变量按区覆盖，便于一色系换色。
