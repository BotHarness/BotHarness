# Avatar Species and Custom Parts — specification handoff

Date: 2026-10-08. Status: complete design synthesis; runtime implementation is not delivered.

The product goal is more animals, fantasy species and decorations for the pixel Avatar, now also the Window Companion mascot ([#1135](https://github.com/BotHarness/DeepSeekBot/issues/1135)), and letting Humans draw their own parts in the app. Human confirmed every answer below and the final summary in a grilling session on 2026-10-08. No issue, milestone or Project was created; decomposition into a spec issue and tracer-bullet issues is for Human to request.

## Authorities

- [ADR-0148](../adr/0148-avatar-species-and-custom-parts-extend-one-pixel-rig.md), which partially supersedes the free-drawing and upload limits of [ADR-0118](../adr/0118-editable-avatar-appearance-is-independent-of-activity.md).
- [Glossary](../../CONTEXT.md): Avatar Species, Custom Part and Part Library; Avatar Appearance now includes species and Custom Parts.
- [Living architecture §5.4](../architecture/botharness-architecture.en.md#54--avatar-species-and-custom-parts-accepted-design-not-yet-implemented) and its Chinese counterpart.
- [Pixel-part editor UX research](2026-10-08-pixel-part-editor-ux.md) for tool behavior; [anime 32×32 bust techniques](2026-10-04-anime-32px-bust-pixel-art.md) for artwork.

## Confirmed decisions

| #   | Decision                                                                                                                                                                                                                                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Q1  | Three layers following character-creator practice: Family (skeleton and visual language) → Species (base and compatibility on one rig) → parts. Only a different skeleton makes a new Family.                                                                                                          |
| Q2  | Animals are anthropomorphic busts; kemonomimi stay headpieces; full-body pets are out of scope.                                                                                                                                                                                                        |
| Q3  | Not many accessory slots. Side hair splits left and right; bangs, left, right, back and a single strand each take their own color (default: main hair color). A new through-hair headpiece slot has front and back layers; the existing accessory slot stays. Back wings are not in the first version. |
| Q4  | Editor random covers everything. New PersonaBots record a full-domain seed version; PersonaBots without it keep the human-only seed. An Avatar follows its name until edited, then stays fixed across renames.                                                                                         |
| Q5  | Every species ships with the full rig: transparent silhouette, anchors, gaze, blink, turns, closed/half-open/open speech mouth.                                                                                                                                                                        |
| Q6  | New species, slots or Custom Parts raise the asset/schema version; older Clients show the saved snapshot; existing recipes render byte-identically.                                                                                                                                                    |
| Q7  | Custom Part cells are color source (appearance color slot or fixed color) plus tone step.                                                                                                                                                                                                              |
| Q8  | The Part Library is the authoring source; applying embeds a copy in the Appearance; parts travel with exported PersonaBots.                                                                                                                                                                            |
| Q9  | Record the change as a new ADR (0148).                                                                                                                                                                                                                                                                 |
| Q10 | Gradient steps tones with ordered dither; noise jitters tones; both bake into cells at draw time.                                                                                                                                                                                                      |
| Q11 | Importing a PersonaBot or part file adds its parts to the library automatically; the library UI filters by origin.                                                                                                                                                                                     |
| Q12 | A single part exports as a PNG with embedded part data and reimports losslessly, animating like a built-in part; the library exports as a zip.                                                                                                                                                         |
| Q13 | Plain PNGs of slot size import with a bounded color count as fixed colors.                                                                                                                                                                                                                             |
| Q14 | Tools: pencil, eraser, fill, gradient, noise, mirror, line, rectangle, eyedropper, undo/redo, 1× live preview. No layers, frames or selection transforms.                                                                                                                                              |
| Q15 | The library is Host-owned Profile data. BotPixel owns part data, validation, rendering and drawing algorithms; DeepSeekBot owns the editor, library and import/export.                                                                                                                                 |
| Q16 | Part content is immutable; its ID is a content hash; duplicates merge and record each origin.                                                                                                                                                                                                          |
| Q17 | Parts keep name and author as plain metadata; edits create a new part recording its parent.                                                                                                                                                                                                            |
| Q18 | Built-in and others' parts can be opened and edited into a new part; built-in shapes are fixed at the current recipe.                                                                                                                                                                                  |
| Q19 | Species: human, elf, goblin, dwarf, orc, cat, dog, fox, rabbit, bear, flower.                                                                                                                                                                                                                          |
| Q20 | Switching species replaces base parts, keeps the rest, and hides but keeps incompatible choices until they fit again.                                                                                                                                                                                  |
| Q21 | Skin color becomes body color; per-species suggested swatches; free choice stays; animals get a pattern part in body-color tones.                                                                                                                                                                      |
| Q22 | Custom Parts may fill headpiece, accessory, hair-piece and pattern slots; eyes, brows and mouth are not drawable.                                                                                                                                                                                      |
| Q23 | Custom Parts follow their slot anchor; turns are derived by slot shift and far-side rules; drawn turn variants may come later.                                                                                                                                                                         |
| Q24 | The editor draws headpiece front and back layers explicitly, with hair occlusion in the preview.                                                                                                                                                                                                       |
| Q25 | First slice: goblin, split colored side hair, minimal editor, one headpiece through library → PersonaBot → Window Companion → export/import.                                                                                                                                                           |
| Q26 | Flower is a species: petals replace hair, stem/leaves/pot replace the outfit.                                                                                                                                                                                                                          |
| Q27 | Medieval set: dwarf and orc species; armor, robe, tunic, cloak outfits; helmet and hood accessories that hide hair while worn.                                                                                                                                                                         |
| Q28 | Beards are a lower-face part that always leaves the mouth visible; mouth-covering parts are not in the first set.                                                                                                                                                                                      |

## Tracer bullets

| Stage        | Observable path                                                                                                                                                                                                             |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| First slice  | Goblin species and split colored side hair in BotPixel; minimal editor draws one headpiece, saves to the Part Library, applies to a PersonaBot that animates and speaks as a Window Companion; export/import keeps the part |
| Editor depth | Gradient, noise, line, rectangle, eyedropper, PNG export/import, derived editing from built-in and imported parts                                                                                                           |
| Species      | Elf, dwarf, orc; cat, dog, fox, rabbit, bear with patterns; flower; medieval outfits and accessories; beards                                                                                                                |

Each slice keeps BotPixel's golden fixture unchanged for existing recipes and runs through the real PersonaBot owning module and Host↔Client seam, not a test-only store.
