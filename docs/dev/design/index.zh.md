- [Living architecture](/zh/dev/design/architecture)：系统上下文、deep modules、authority、持久化与数据流。
- [Bot runtime 架构](/zh/dev/design/bot-runtime)：BotHarness 产品对象与 DSH execution 之间的聚焦关系。
