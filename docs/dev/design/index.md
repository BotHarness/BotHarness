# Design

Design pages define BotHarness product meaning and intended architecture.

- [Domain glossary](/dev/design/context): the single authority for PersonaBot, Channel, Source Event, Bot Inbox, Orchestrator Session, Work Session, and related product terms.
- [Platform specification](/dev/design/platform): product invariants and cross-cutting behavior.
- [DeepSeekBot PRD](/dev/design/app-prd): the first application's product requirements.
- [Living architecture](/dev/design/architecture): system context, deep modules, authority, persistence, and data flow.
- [Bot runtime architecture](/dev/design/bot-runtime): the focused relationship between BotHarness product objects and DSH execution.

These pages are normative design sources. For the currently implemented code surface, use [Reference](/dev/reference).
