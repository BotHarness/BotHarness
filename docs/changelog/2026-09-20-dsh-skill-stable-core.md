---
title: 'DSH skill narrows to stable context and decisions'
date: 2026-09-20
tags: [docs, dsh, skill]
---

The installable DSH skill now publishes only the stable DSH/Cordis Context and architectural Decision Tree. Its canonical vocabulary and three concept maps remain available to agents and people, while version-sensitive Host, Client, Slot, and community implementation catalogs have been removed from the skill and documentation site.

Historical implementation surveys remain in the canonical repository under `docs/research/`. Existing Guide, Host, Client, Slots, and Patterns URLs permanently redirect to the surviving foundation pages.
