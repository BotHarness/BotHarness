## 安装调研

- `docs/research/2026-09-18-dsh-plugin-installation.md`：`dsh plugin --profile <p> <args...>` 只是 profile 目录内的 pnpm 转发；bundle 声明 `dsh.bundle.patch`，装进 `dsh.profile.bundles`；DSH 自带插件管理器（侧边栏 Plugins 页 + 只读设置清单），但无官方 marketplace、无 `/plugin` 命令；bundle 成员变化需重启。
- 验证环境：pin `@deepseek-ai/dsh@0.1.5-rc.2`、独立 `DSH_HOME`、从 `web` 模板派生专用 profile、官方 CLI 或 tarball 安装——第三方市场插件不进本门。
