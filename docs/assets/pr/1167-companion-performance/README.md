See [the research checkpoint](../../../research/2026-10-09-window-companion-performance.md) for exact sources, measurement protocol, limitations and open acceptance gates. [same-version-controls-pilot.json](./same-version-controls-pilot.json) adds twelve five-second walking samples with the same formal Avatar0.8.0 and durable Profile at pinned main d55d82fe / #1173 source50b44535. [formal-gpu-process.json](./formal-gpu-process.json) separately records five scenes with fifteen one-second Windows GPU-process intervals each at accepted formal0.10.1 sourcea0096785. Neither collection qualifies an agreed performance budget, and process GPU counters do not establish an SVG-only cost or hardware backend. Screenshots record actual measured states; they are not an isolated visual before/after comparison. Raw traces/heaps, process identities and authentication data are deliberately excluded.
